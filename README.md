# BestShopio Storefront

BestShopio 消费者商城原型，对应买家浏览、商品、购物车、Checkout、支付、订单和客户中心等完整购物体验。

## 产品边界

- 本目录是 BestShopio 完整 Storefront，不是 BestCheckout 官网。
- BestCheckout 的 Checkout Surface、Funnel、Upsell/Downsell 和 Thank-you 能力可以在该 Storefront 中原生运行。
- 当 BestCheckout 商家升级到完整 BestShopio 时，应尽量复用已有 Checkout 页面、Funnel、支付连接引用和转化配置，而不是重新搭建。

## 页面

- `index.html`：购物车、结账、账户的预览入口
- `home.html`：首页
- `collection.html`：商品集合页
- `collections.html`：集合列表
- `official-site/index.html`：BestShopio 官网
- `official-site/help/index.html`：帮助中心
